# 背景

Vela 是一个 iPhone App。手机固定在 Tesla 车内支架上，通过蓝牙直连车辆，当副屏用。不联网，不登录 Tesla 账号。

现在工程已经能跑，蓝牙能读到的数据比原设计稿多得多。这次要做的是：把蓝牙能拿到的信息都设计进去，每一项都让用户自己决定显示还是隐藏。默认只开最基本的几项，保持现在安静、克制的样子。

# 总原则

1. **车速永远是主角。** 仍然是屏幕上唯一超过 60 pt 的元素。新增的信息都是可选模块，不能挤占车速。
2. **分开设计「行驶中」和「停车时」。** 行驶中只显示看一眼就懂的信息。停车时（P 档、车速为 0）可以显示更多、可以操作更多。
3. **模块化。** 沿用 Layout 页的「Modular deck」规则：每个模块自己决定高度，关掉或者车没上报，模块就直接消失，不画空状态。
4. **竖屏、横屏都是正式场景。** 每个新模块都要给出竖屏和横屏的摆法。
5. **深色、浅色都要画。** 包括 Speed display 里的 Graphite 和 Paper 两种底色。
6. **所有数字都是车实际上报的值。** 不画需要推算或估计的数据。

## 8. 胎压

四个轮胎各自的气压（bar，可按用户单位换算成 psi），每个轮胎的轻微警告和严重警告，以及推荐冷胎压。

建议：平时不显示。有警告时自动出现一个小模块，指出是哪个轮胎。另外在停车时可以打开一张俯视车身的胎压图。

## 9. 媒体（已有，补充）

曲名、歌手、专辑名、电台名、音源名称（比如手机蓝牙的设备名）、音源类型、进度、总时长、音量。

**播放 / 暂停状态可以拿到了。** 播放键请按原设计：播放中显示暂停图标，暂停时显示播放图标。

专辑封面仍然拿不到。Now Playing 页那块大封面请缩小或者换成别的，比如大号的曲名，或者音源信息。

## 10. 软件更新

版本号、更新状态、下载进度、安装进度、预计安装时长、计划安装时间。停车时可以显示「有更新可安装」。

# 可以发出的操作

除了已经设计的空调和音乐，蓝牙还能执行下面这些。请只放在停车时能进入的地方，行驶中不要出现：

- 锁车、解锁
- 开前备箱、开关后备箱
- 车窗通风、关窗，开关天窗
- 鸣笛、闪灯
- 哨兵模式开关
- 开关充电口、开始 / 停止充电、设置充电上限和充电电流
- HomeLink（开车库门）
- 音乐的下一个 / 上一个收藏
- 音量直接设到某个值

# 做不到的，请不要画

- FSD、Autopilot 的任何状态
- FSD 目标车速
- 道路限速
- 导航的转向提示、路线形状
- 转向灯、盲区提醒、大灯状态
- 车主给车起的名字（只能显示 Model 3 / Y / S / X / Cybertruck）
- 专辑封面
- 调风量、风量 Auto
- 远程唤醒睡着的车

# 需要新增或修改的画面

1. **仪表盘自定义页。** 放在 Settings 里。列出所有可选模块，每个都能开关。竖屏和横屏各自决定哪些模块出现、按什么顺序排。要有预览。
2. **仪表盘的新模块。** 功率、续航、导航、车内外温度、朝向、胎压警告、车门提醒等。每个模块都要给出竖屏和横屏两种尺寸。
3. **行驶中和停车时的两种仪表盘。** 停车时可以多显示一些，并且提供进入车辆控制、超充站、胎压图的入口。
4. **充电中画面。**
5. **附近超充站页面。**
6. **车辆控制页面。** 锁车、前后备箱、车窗、哨兵、充电口等，只在停车时能进入。
7. **胎压和车身俯视图。**
8. **空调页改版。** 去掉风量按钮，加入座椅加热、座椅通风、方向盘加热。
9. **Now Playing 改版。** 播放键区分播放和暂停。处理拿不到专辑封面的问题。
10. **地图模块（可选）。** 需要联网。不联网时退回只显示朝向和位置名称。

# 顺便补上原设计稿缺的状态

- **「输入 VIN」页。** 放在「Choose your car」之后。蓝牙广播里没有 VIN，配对又必须用 VIN。用户要在这里输入 17 位 VIN。输错或者和选中的车对不上时，要显示错误。
- **「Choose your car」列表。** 每辆车只能显示「Tesla」，拿不到车型或车名。距离只能分档：很近、附近、稍远、很远，不能写「10 m」。
- **蓝牙已关闭。**
- **蓝牙权限被拒绝。** 需要一个去系统设置的按钮。
- **配对失败或超时。** 在「Confirm in your car」页，要有失败说明和「再试一次」。
